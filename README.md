# archivos-md

Repositorio que reúne kits, plantillas de automatización, workflows y documentación sobre inteligencia artificial aplicada al marketing, la prospección de clientes y la creación de contenido. Incluye material de formaciones, plantillas listas para importar en n8n y guías prácticas.

## Contenido

- **`recursos/kits/`** — Kits de código y skills (auditoría de negocio, SEO, Meta Ads, scraping web, dashboards…).
- **`recursos/plantillas-n8n/`** — Plantillas de workflows n8n listas para importar (recepcionista, prospección automática, redes sociales, vídeos virales…).
- **`recursos/cursos/`** — Material de formaciones sobre agentes de IA, Claude Code, Hermes Agent y más.
- **`recursos/workflows-n8n/`** — Workflows sueltos en JSON (WhatsApp, Instagram, LinkedIn, AutoShorts…).
- **`recursos/documentos/`** — PDFs y documentos de apoyo (guiones de llamada en frío, master prompt, setup de OpenClaw…).
- **`reglas-responsive/`** — Reglas y buenas prácticas de diseño responsive (accesibilidad, compatibilidad multi-dispositivo, rendimiento, theming).
